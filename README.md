# j0bSearch

A small Python project for searching Berlin-based working-student jobs in media and IT-related fields, combining results from multiple job sources and exporting the matches to a PDF.

This repository is intentionally lightweight and focused on a single workflow: fetch job listings, normalize them, filter by a custom rule set, and generate a readable PDF report.

## What it does

- Fetches job listings from:
  - Arbeitnow
  - Google Jobs via SerpAPI
- Normalizes the different API payloads into one common structure
- Filters jobs for:
  - Berlin location
  - working student / internship type
  - media or IT-related keywords
- Exports the matching jobs to a PDF file

## Project structure

- `main.py` — orchestrates the fetch, normalize, filter, and export flow
- `arbeitnow.py` — fetches jobs from the Arbeitnow job board API
- `google.py` — fetches jobs from Google Jobs using SerpAPI
- `normalizer.py` — converts each source's output to a unified format
- `filters.py` — applies the repo-specific filtering logic
- `pdf_export.py` — exports filtered jobs to a PDF report
- `werkstudent_berlin.pdf` — example output generated by the script

## Requirements

Python 3.9+ is recommended.

Install dependencies:

```bash
pip install requests python-dotenv reportlab
```

## Configuration

The Google Jobs integration uses SerpAPI.

Set the environment variable before running the script:

```bash
export SERPAPI_KEY="your_api_key_here"
```

On Windows PowerShell:

```powershell
$env:SERPAPI_KEY="your_api_key_here"
```

## Usage

Run the main script:

```bash
python main.py
```

The script will:

1. Load jobs from Arbeitnow and Google Jobs
2. Merge and normalize the results
3. Apply filters for Berlin working-student media/IT roles
4. Save a PDF report named `werkstudent_berlin.pdf` if matches are found

## Filtering logic

The project currently looks for jobs matching these criteria:

- location includes Berlin
- job type is related to working student / internship
- job title, tags, or description contains at least one:
  - media keyword, or
  - IT / software / programming keyword

## Notes

This project is designed as a quick, personal job-search utility rather than a production-ready service.

It relies on external APIs and is tuned to a specific search use case, but the code is simple enough to adapt for other filters, other cities, or alternative sources.
